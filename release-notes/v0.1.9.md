## EzPaste v0.1.9

### ✨ New
- **Quick Start guide:** a short guide opens the first time you start v0.1.9. Open it again any time from **❓ Manual → 🚀 Quick Start**.
- **Choose what [X] does:** clicking **[X]** asks whether to **put EzPaste away** (taskbar + tray) or **quit**. Tick **Remember my choice** to skip the question. To be asked again, use **⚙️ Data Center** or the tray menu.
- **Ctrl+Q** quits EzPaste straight away.
- **Menu on the blue edge tab:** right-click the tab for **Show / Put away / Quit**.

### 🐞 Fixes and improvements
- **Light / dark switch:** the window no longer disappears and reappears as if it had restarted.
- **Hiding at the screen edge is reliable again:** it no longer stops working after minimizing, **Win+D** or **Alt+Tab**.
- **No more growing window:** on screens with Windows display scaling above 100 %, the window no longer gets bigger each time it slides in or out.
- **Fewer accidental pop-outs:** a tucked window slides out only after the mouse rests on the edge for a moment, or when you click the tab. The slide is smoother too.
- **Two or more screens:** EzPaste only tucks away on the outer right edge, not between screens.
- **Stays out of the way:** while open, EzPaste no longer shows up in **Alt+Tab / Win+Tab** or on the taskbar. When you put it away, a taskbar button appears so you can click it back.
- **Faster:** searching, switching categories and resizing reuse the reply cards instead of rebuilding them all.

### ℹ️ Notes
- **Updating from v0.1.7 or v0.1.8:** click **Update now** inside the app. Your replies, ⭐ Frequent counts, settings and desktop shortcut are untouched.
- **Updating from v0.1.6 or older:** download and run `EzPaste_Setup_v0.1.9.exe` once. **Update now** works from then on.
- **The title bar is a little thinner and has no minimize button.** That's what keeps EzPaste out of Alt+Tab and the taskbar. Use **[X]**, the hotkey or the edge tab instead.
- **Install location:** keep the default folder or pick one you can write to. Don't install into `C:\Program Files`: EzPaste saves its data next to the app, and saving fails there.

## EzPaste v0.1.9 更新说明

### ✨ 新功能
- **快速上手引导：** 首次启动 v0.1.9 时会打开简短的使用引导，之后可随时在 **❓ 说明 → 🚀 快速上手** 中再次打开。
- **自选 [X] 的操作：** 点击 **[X]** 时会询问是 **收起**（任务栏 + 托盘）还是 **退出**。勾选 **记住我的选择** 后不再询问；如需重新询问，可在 **⚙️ 数据中心** 或托盘菜单中设置。
- **Ctrl+Q** 立即退出 EzPaste。
- **贴边蓝色标签菜单：** 右键标签可选择 **显示 / 收起 / 退出**。

### 🐞 修复与改进
- **切换浅色 / 深色：** 窗口不再像重启一样消失再出现。
- **贴边隐藏恢复稳定：** 最小化、**Win+D** 或 **Alt+Tab** 之后不会再失效。
- **窗口不再变大：** 在 Windows 显示缩放大于 100% 的屏幕上，窗口每次滑入滑出不会再变大。
- **减少误弹出：** 收起后，鼠标需在屏幕边缘停留片刻（或点击蓝色标签）才会展开，滑动也更顺滑。
- **多显示器：** 只在最外侧的右边缘贴边收起，不会卡在两个屏幕之间。
- **不再打扰：** 窗口打开时不会出现在 **Alt+Tab / Win+Tab** 和任务栏中；收起后会显示任务栏按钮，点击即可还原。
- **更快：** 搜索、切换分类、调整窗口大小时复用回复卡片，不再全部重建。

### ℹ️ 说明
- **从 v0.1.7 或 v0.1.8 更新：** 在应用内点击 **立即更新** 即可。你的回复、⭐ 常用记录、设置和桌面快捷方式都不会受影响。
- **从 v0.1.6 或更早版本更新：** 请下载并运行一次 `EzPaste_Setup_v0.1.9.exe`，之后即可使用“立即更新”。
- **标题栏变窄，并且没有最小化按钮。** 这样 EzPaste 才不会出现在 Alt+Tab 和任务栏中。请改用 **[X]**、快捷键或贴边标签。
- **安装位置：** 使用默认文件夹，或选择你有写入权限的位置。请不要安装到 `C:\Program Files`：EzPaste 的数据保存在程序旁边，安装在那里会导致无法保存。
